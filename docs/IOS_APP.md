# iOS app spec

UI spec: `design-system/orbit/pages/ios.md`. This file covers behavior and engineering.

## Targets & build
- Deployment target is iOS 16.0. Bundle ID `dev.orbitstore.Orbit`; URL scheme `orbit`.
- The project is generated by **XcodeGen** (`ios/project.yml`) so there's no hand-edited `.pbxproj` and CI regenerates it.
- CI: `xcodegen generate && xcodebuild … CODE_SIGNING_ALLOWED=NO`, then zip `Payload/Orbit.app` into `Orbit.ipa` and upload it as an artifact.
- Entitlements: **none beyond the defaults** (free-account safe). Keychain access group = own team prefix.

## Modules (Swift packages inside `ios/Packages/`)

| Package | Responsibility |
|---|---|
| `OrbitKit` | Models, API client (`/api/*`), token store, report builder |
| `OrbitAnisette` | Anisette v3 client: client_info, provisioning WebSocket, get_headers, local `adi.pb` + client ID storage. Sends `Authorization: Bearer` to the gateway |
| `OrbitApple` | Apple GSA auth (SRP) + 2FA, developer services (certs, App IDs, profiles), using SideStore AltSign/related code |
| `OrbitDevice` | Pairing record load/validate, loopback connection (SideStore library per P01), install/remove/list apps, VPN reachability probe |
| `OrbitSigning` | IPA unpack, bundle ID remap (`<orig>.<teamID>` style), entitlement filtering to free-safe set, re-sign, repack |
| `OrbitRefresh` | Refresh planner + executor, BGTask registration, App Intents, local notification scheduler |
| `OrbitUI` | Design system (`OrbitTheme.swift`) + shared components |

## Refresh engine

- **Planner:** select apps where `expiresAt - now ≤ refreshWindow` (default 48h; user-configurable 24–96h). Always include Orbit itself (or the LiveContainer host) when it's due.
- **Preflight (fail fast, each with its own error code + fix text):**
  - `VPN_OFF`: loopback probe failed. Fix: open LocalDevVPN.
  - `PAIRING_INVALID`: lockdown handshake rejected. Fix: re-pair flow.
  - `APPLE_REAUTH_2FA`: session expired and 2FA is required. Fix: local notification "Tap to confirm your Apple ID".
  - `APP_ID_LIMIT`: 10/7d exhausted. Fix: show the date when the next slot frees.
  - `ANISETTE_UNAVAILABLE`: gateway error. Fix: retry with backoff; show server status.
- **Executor:** run apps sequentially, Orbit last. Each step is checkpointed so a background expiry can resume. Report every attempt to the server.
- **Triggers:**
  - `BGAppRefreshTask` id `dev.orbitstore.Orbit.refresh`: requested earliest at the next window. Best effort.
  - `BGProcessingTask` id `dev.orbitstore.Orbit.refresh.long`: requires external power is false, network true.
  - **App Intent `RefreshAppsIntent`** ("Refresh Apps in Orbit"): `openAppWhenRun = false`, returns a summary string for Shortcuts. This is the reliable path via a personal automation (daily, time of day).
  - App launch + foreground: run if any app is due.
- **Notifications** (local, `UNUserNotificationCenter`): rescheduled after every run at T-48h / T-24h / T-6h before the earliest expiry. Immediate notification on failure with the fix text. Category actions are "Refresh now" and "Open LocalDevVPN".

## Re-pair flow
Trigger: `PAIRING_INVALID` twice in a row, or the user taps "Re-pair". The screen explains why it happens (iOS updates/resets) and walks through it: (1) open Orbit Setup on a computer and choose "Re-pair only", or (2) import a pairing file from Files. After import, validate immediately and show the result.

## Apple ID handling
- The SRP login + 2FA UI uses `.username` / `.password` / `.oneTimeCode` content types so password managers and SMS autofill work.
- Keychain items: `apple.username`, `apple.password` (optional, "Remember for automatic refresh", default ON with an explainer), `apple.session`, `dev.cert.p12` (+ password), `anisette.clientId`, `anisette.adi`.
- "Sign out of Apple ID" wipes all of the above after a confirmation, and offers to revoke the certificate.

## App sources
- Supports the AltStore source JSON format (`name`, `identifier`, `apps[]` with `versions[]`, `downloadURL`, `size`, `minOSVersion`, `appPermissions`).
- Before install, show the size, permissions/entitlements (with filtered ones marked "not available on free accounts") and the source domain.
- The download goes directly from the source URL to the device. Orbit servers don't host IPAs.

## Server sync
- `POST /api/devices` on first launch after login (uses the anisette client ID).
- `POST /api/devices/{id}/report` after each refresh attempt, install/remove and on launch (throttled to once per 10 min). Reports are queued offline and sent later.
